# Plan: Fix Museum to Only Show Points Profits

## Issue

When re-selling Plushies/Flowers (via normal sell transactions), their profits are incorrectly being added to the Museum profit display. The Museum should only show profits made by selling points.

## Root Cause

In both `lib/chartUtils.ts` (line 174) and `app/page.tsx` (line 161), items in `MUSEUM_TRACKED_ITEMS` are treated as museum items:

```typescript
const isMuseum =
    name.toLowerCase() === "points" ||
    name.toLowerCase() === "flushie" || // typo: should be "plushie"
    MUSEUM_TRACKED_ITEMS.includes(name.toLowerCase());
```

`MUSEUM_TRACKED_ITEMS` contains individual flower/plushie names (e.g., "ceibo flower", "sheep plushie"). When these items are resold, their realizedProfit is added to museumProfit.

## Fix Required

### 1. Fix `lib/chartUtils.ts` (line 171-174)

Change the museum check to only include "points":

```typescript
const isMuseum = name.toLowerCase() === "points";
```

### 2. Fix `app/page.tsx` (line 158-161)

Same change - only include "points":

```typescript
const isMuseum = name.toLowerCase() === "points";
```
