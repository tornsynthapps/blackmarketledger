# Plan: Add Blackbox Logging to Auto-Pilot and Create Blackbox Viewer Page

## Goal

1. Modify `syncNow` in `/auto` page to create a Blackbox instance and log comprehensive sync data
2. Create a new `/blackbox` page to view all blackboxes and their data

## Changes Required

### Part 1: Update syncNow in app/auto/page.tsx

**File:** `app/auto/page.tsx`

**Changes:**

1. Import `Blackbox` from `@/lib/blackbox`
2. At the start of `syncNow`, create a new `Blackbox` instance
3. Log the following events with timestamps:
    - Sync start event (includes cursors, API keys presence)
    - Pre-sync items (items before autoSync started - use itemCursor)
    - Sync start timestamp
    - Item fetch results (count, timestamps)
    - Item import results (count)
    - Trade fetch request (Torn API call)
    - Trade fetch response (count, timestamps)
    - Receipt fetch request
    - Receipt fetch response (count)
    - Trade-receipt linking (each linked pair)
    - Unlinked trades count
    - Unlinked receipts count
    - Import results (count of logs imported)
    - Sync completion (final cursor state)
    - All console.log outputs (by capturing them)
    - Any errors/failures
4. Save the blackbox at the end of sync (in finally block or after completion)

### Part 2: Create /blackbox page

**New File:** `app/blackbox/page.tsx`

**Features:**

1. List all blackboxes stored in localStorage (from `ledger-blackbox` key)
2. Show blackbox ID, creation timestamp
3. Click to view details at `/blackbox?id=XX`
4. Display all logged events with timestamps
5. **Filtering/search** - filter events by type or search text
6. **No auto-cleanup** - all blackboxes retained indefinitely
7. Option to clear/delete individual blackboxes

**Implementation Approach:**

- Use `Storage.getDictFromLocalStorage(Blackbox.STORAGE_KEY)` to get all blackboxes
- Parse each blackbox's logs (stored as JSON string)
- Display in a clean UI with collapsible events and search/filter

## Key Data Points to Log in Blackbox

| Event                  | Data                                       |
| ---------------------- | ------------------------------------------ |
| Sync Start             | timestamp, cursors, apiKeysPresent         |
| Pre-Item-Sync          | itemCursor, tradeCursor, timestamp         |
| Item Fetch             | category counts, timestamps, newItemCursor |
| Item Import            | count, success/failure                     |
| Trade Fetch Request    | startTimestamp, endTimestamp               |
| Trade Fetch Response   | tradeCount, tradeIds                       |
| Receipt Fetch Request  | startTimestamp, endTimestamp               |
| Receipt Fetch Response | receiptCount, receiptIds                   |
| Trade-Receipt Link     | tradeId, receiptId, itemsLinked            |
| Unlinked Trades        | count, tradeIds                            |
| Unlinked Receipts      | count, receiptIds                          |
| Import Result          | logCount, success/failure                  |
| Sync Complete          | finalCursors, unlinkedCount                |
| Errors                 | errorMessage, stack                        |
