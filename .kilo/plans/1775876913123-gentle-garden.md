# Plan: Under Construction Page Component

## Goal

Create an Under Construction page component that shows when a page is under construction in production mode, but shows the incomplete page in development mode.

## Requirements

1. Create UnderConstructionPage component
2. Create test page at `/treasurechest/debug/underconstruction`
3. Use environment variable for production mode detection

## Implementation

### Step 1: Add environment variable to .env.local

- Add `NEXT_PUBLIC_PRODUCTION_MODE=false` to `.env.local` (development mode, shows incomplete pages)
- In production environment: `NEXT_PUBLIC_PRODUCTION_MODE=true` (shows Under Construction page for pages marked as under construction)

### Step 2: Create UnderConstructionPage component

- Location: `components/UnderConstructionPage.tsx`
- Shows a "Under Construction" styled page with warning styling
- Takes optional `message` prop for custom message
- Uses hugeicons for visual

### Step 3: Create helper hook

- Location: `lib/useProductionMode.ts`
- Returns `isProduction` boolean based on `process.env.NEXT_PUBLIC_PRODUCTION_MODE`

### Step 4: Create test page

- Location: `app/treasurechest/debug/underconstruction/page.tsx`
- Shows a sample page with underConstruction=true
- When isProduction=true, shows UnderConstructionPage overlay
- When isProduction=false, shows the "incomplete" page content
- Allows toggling the flag to test both states

### Step 5: How pages will use it

- Each page exports `underConstruction = true` to mark itself
- If `isProduction && page.underConstruction`, show UnderConstructionPage instead of the incomplete content

## Files to create/edit

- `components/UnderConstructionPage.tsx` (new)
- `lib/useProductionMode.ts` (new)
- `app/treasurechest/debug/underconstruction/page.tsx` (new)
- `.env.local` (edit - add NEXT_PUBLIC_PRODUCTION_MODE=false)

## Notes

- The env variable approach is clean and doesn't require code changes per-page
- Pages mark themselves as under construction by exporting a flag
- In production mode with under construction page, show the Under Construction placeholder
- In development mode, show the actual incomplete page for testing
