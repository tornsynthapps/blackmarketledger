### 3. New Algorithm: Compute Buy Plan by Number of Items

**Files:** `app/museum/page.tsx`

Create new function `computeBuyPlanByItems`:

```
- Input: items array, number of different items (N)
- Sort items by stock ascending
- Take first N items (least stock)
- Target = stock of Nth item (or Nth item's stock if N items specified)
- For each of N items: buy = target - current stock
- Return purchase plan with items sorted by stock ascending
```

Example logic:

- If N=1: target = least item stock, only that item needs buying
- If N=3: target = 3rd least item stock, all 3 least items buy to reach that level

### 5. New Algorithm: Compute Buy Plan by Number of Items

**Files:** `app/museum/page.tsx`

Create new function `computeBuyPlanByItems`:

```
Algorithm (based on user's example):
- Input: items array, number of different items (N)
- Sort items by stock ascending (least to most)
- Target = stock of (N+1)th item (the item just after the N items we're buying)
- For each of first N items: buy = target - current stock
- If N >= total items, target = stock of last item (no buying beyond that)

Examples:
- N=1: Target = 2nd least item stock. Buy 1st item to match 2nd.
- N=3: Target = 4th least item stock. Buy 1st-3rd items to match 4th.
- N=total-1: Target = last item stock. Buy all but last to match last.
```

Example from user:

- Items: Kitten(5), Wolverine(19), Nessie(27), Chamois(30), ...
- N=1: Target=19 (Wolverine), buy 14 of Kitten (19-5)
- N=3: Target=30 (Chamois), buy 25 Kitten, 11 Wolverine, 3 Nessie
