# Plan: Merge torn-api.ts into api.ts

## Goal

- Update `lib/game/api.ts` with proper documentation comments per INSTRUCTIONS.md
- Move only necessary content from `lib/torn-api.ts` into `lib/game/api.ts`
- Reuse existing OOP classes where possible
- Delete `lib/torn-api.ts`

## Current State

### `lib/game/api.ts` (211 lines)

- Contains `TornAPI` and `T3BAPI` classes
- Already uses rate limiting, makes API requests to Torn and Weav3r

### `lib/game/trade.ts` (651 lines) - ALREADY HAS OOP!

- `TornTrade` class with methods: `compareReceipt()`, `compareAndLinkReceipt()`, `expandSetItems()`, `isIncoming()`, `hasOnlyOneMoneyItem()`, `getTotalValue()`
- `Weav3rReceipt` class with: `fromApiResponse()`, `fromInterface()`, `toInterface()`
- `Weav3rReceiptItem` class

### `lib/torn-api.ts` (1098 lines) - TO CLEAN UP

- Has redundant functions already in trade.ts: `summarizeTrade`, `compareTradeAgainstReceipt`, `findMatchingReceipt`, `createParsedLogsFromReceipt`, `createParsedLogsFromNewReceipt`
- Has standalone log fetching: `getTornLogs`, `getNewLogs`, `getTornItems`
- Has rate limiter setup: `refreshApiRateLimiters`
- Has parsing: `normalizeTornLog`, `parseNormalizedLog`
- Has interfaces: `SyncCursor`, `TornLogEntry`, etc.

| `buildUrl()`               | Utility, private static | Helper                                              |

### Step 3: Reuse trade.ts Instead of Duplicating

DELETE these redundant functions from torn-api.ts when merging:

- `summarizeTrade()` - Use `TornTrade` methods instead
- `compareTradeAgainstReceipt()` - Use `TornTrade.compareReceipt()`
- `findMatchingReceipt()` - Implement using trade.ts classes
- `createParsedLogsFromReceipt()` - Implement using trade.ts `expandSetItems()`

- `TornItemNameMap` - For item mapping

### Step 5: Create New Class Structure

Create `TornDataAPI` class in api.ts with:

- Rate limiting (private static)

- Instance: `getTornLogs()`, `getNewLogs()`, `getTornItems()`

### Step 6: Update Imports

- Update imports in files that depend on `torn-api.ts` to use `lib/game/api.ts`
- Add necessary imports to `api.ts`

### Step 7: Delete torn-api.ts

Delete `lib/torn-api.ts` after all references are updated
