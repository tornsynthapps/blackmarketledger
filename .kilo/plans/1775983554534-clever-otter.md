# Plan: Toggle Buttons Preview Page

## Goal

Create a new page at `/treasurechest/preview/buttons` showcasing toggle button components following the "Hardline Interface" design system.

## Design System Constraints (from DESIGN.md)

- No border-radius (strictly `0px`)
- Thick borders (2px)
- High contrast
- Color inversion on hover
- Position shift on active/press
- Monospace + grotesque font pairing
- Hard offset shadows

## Implementation

### 1. Create Page File

**Path:** `app/treasurechest/preview/buttons/page.tsx`

### 2. Toggle Button Variants to Implement

| Variant       | Description                                       | Key Style                       |
| ------------- | ------------------------------------------------- | ------------------------------- |
| **Classic**   | Standard hardline toggle - solid fill with border | Inverts colors on hover         |
| **Outline**   | Border-only with transparent background           | Fills on hover, border emphasis |
| **Accent**    | Uses accent colors (red, blue, green, yellow)     | Color-coded toggle states       |
| **Icon**      | Toggle with Hugeicons icon                        | Icon-based state indicator      |
| **Segmented** | Group of options in button group                  | Radio-style toggle group        |
| **States**    | Disabled, loading, loading-with-icon states       | All button states               |

### 3. Component Structure

Each variant will show:

- **Off state** (default)
- **On state** (toggled)
- **Hover state** (mouse over)
- **Disabled state** (if applicable)
- **Loading state** (if applicable)

### 4. Page Layout

- Header with back link to Treasure Chest
- Grid layout showcasing each variant
- Labels and descriptions for each button style
- Interactive toggles (functional)

### 5. Dependencies

- Use existing `Hugeicons` from `@hugeicons/react`
- Use existing CSS variables from `globals.css`
- Reuse patterns from `treasurechest/reset-cursor/page.tsx`
