# Data

This directory contains static data, API definitions, and reference materials used by the Black Market Ledger application.

## Subdirectories

- [torn/](./torn/): Data and API definitions related to the Torn API.
- [tornExchange/](./tornExchange/): API definitions for Torn Exchange.
- [tornW3B/](./tornW3B/): API definitions for TornW3B.
