# Plan: Add Swagger Documentation to /api

## Goal

Host Swagger UI at `/apidocs` endpoint in the Ledger API (Cloudflare Worker).

## Approach

Use `@hono/swagger-ui` package - serves Swagger UI directly from Hono, works in Cloudflare Workers.

## Implementation

### 1. Install Dependency

```bash
npm install @hono/swagger-ui
```

### 2. Create OpenAPI Spec

Create `api/src/utils/openapi.ts` or inline in index.ts:

- Define OpenAPI 3.0 document with info, servers, paths
- Document `/auth/login`, `/auth/signup`, `/auth/reset-token` endpoints

### 3. Add Routes in api/src/index.ts

```ts
import { swaggerUI } from "@hono/swagger-ui";
import { openApiDoc } from "./utils/openapi";

app.get("/doc", (c) => c.json(openApiDoc));
app.get("/apidocs", swaggerUI({ url: "/doc" }));
```

## Routes to Document

| Method | Path              | Summary            |
| ------ | ----------------- | ------------------ |
| POST   | /auth/login       | Authenticate user  |
| POST   | /auth/signup      | Create new account |
| POST   | /auth/reset-token | Reset secret token |

## Alternative Options

If `@hono/swagger-ui` has Cloudflare Workers issues:

- Use `@scalar/hono-api-reference` - similar but Scalar-themed
- Serve static JSON at `/doc` and use CDN-hosted Swagger UI
