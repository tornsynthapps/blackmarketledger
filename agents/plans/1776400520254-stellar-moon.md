# Plan: Create Auth Table D1 Schema

## Goal

Create a D1 database schema file for the auth table in `api/db/schemas`.

## Schema Definition

```sql
CREATE TABLE auth (
  user_id INTEGER PRIMARY KEY,
  auth_secret TEXT NOT NULL,
  is_blocked INTEGER DEFAULT 0,
  is_banned INTEGER DEFAULT 0,
  failed_attempts INTEGER DEFAULT 0
);
```

## Fields

| Column          | Type    | Constraints | Description                      |
| --------------- | ------- | ----------- | -------------------------------- |
| user_id         | INTEGER | PRIMARY KEY | User identifier                  |
| auth_secret     | TEXT    | NOT NULL    | Hashed auth secret               |
| is_blocked      | INTEGER | DEFAULT 0   | Blocked status (0=false, 1=true) |
| is_banned       | INTEGER | DEFAULT 0   | Banned status (0=false, 1=true)  |
| failed_attempts | INTEGER | DEFAULT 0   | Failed login attempt count       |

## Implementation

- Create file: `api/db/schemas/auth.sql`
- Use INTEGER for booleans (SQLite/D1 convention)
- Add indexes if needed for query performance
