# Plan: Populate Item.ts from items.json

## Objective
Populate `@lib/objects/Item.ts` using `@data/torn/items.json`, grouping items by their type and generating static readonly constants for each item.

## Approach
1. Create a temporary Node.js script that:
   - Reads `data/torn/items.json`
   - Groups items by their `type` field
   - Generates TypeScript code with static readonly constants
   - Writes to `lib/objects/Item.ts`

2. The generated file should:
   - Keep the existing `MONEY_ITEMS_MIN_ID` constant
   - Include a static readonly constant for each item, named in SNAKE_CASE
   - Group items by type with section comments (e.g., `// Melee`, `// Primary`, etc.)
   - Include Cash and Points items

## Implementation Details

### Script: scripts/generate-item-constants.mjs
- Read items JSON
- Transform item names to SNAKE_CASE for constant names (e.g., "Glock 17" → `GLOCK_17`)
- Group by type
- Generate formatted TypeScript output

### Type Groups
From scanning items.json, item types include:
- Melee
- Primary
- Secondary
- Defensive
- Candy
- Other
- Special
- Material
- Clothing
- Jewelry
- Tool
- Medical
- Collectible
- Car

### Output Format
```typescript
const MONEY_ITEMS_MIN_ID = 100000;

export class ItemList {
    // Cash and Points
    public static readonly CASH = MONEY_ITEMS_MIN_ID + 1;
    public static readonly POINTS = MONEY_ITEMS_MIN_ID + 2;

    // Melee
    public static readonly HAMMER = 1;
    public static readonly BASEBALL_BAT = 2;
    // ...

    // Primary
    public static readonly SAWED_OFF_SHOTGUN = 22;
    // ...

    // etc.
}
```
