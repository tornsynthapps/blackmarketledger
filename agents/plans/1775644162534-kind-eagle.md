# Plan: Handle Flower/Plushie Sets in Trade-Receipt Linking

## Problem

Trade receipts may contain "Flower Set" (item_id: -1) or "Plushie Set" (item_id: -2) instead of individual items. The current `compareReceipt` function fails to link trades when receipts use sets because it directly compares item_id and quantity, expecting exact matches.

## Example

Receipt has:

```json
{
    "item_id": -1,
    "item_name": "Flower Set",
    "quantity": 1,
    "price_used": 0,
    "total_value": 0,
    "market_price_at_time": 338090
}
```

Trade has individual flowers from the flower set.

### Step 2: Add market price calculation utilities

Create `lib/market-prices.ts`:

1. `calculateSetTotalMarketValue(items: Array<{marketValue: number}>): number` - sum of all MP
2. `calculateItemProportions(items: Array<{id: number; marketValue: number}>): Record<number, number>` - returns map of item_id to percentage of total set MP
3. `getSetItemDistribution(setType: "flower" | "plushie"): Map<number, {name: string; proportion: number}>` - returns map for distribution

### Step 3: Expand set items in receipt comparison

In `lib/game/trade.ts`:

1. Add helper function `expandSetItems(receipt: Weav3rReceipt): Weav3rReceiptItem[]`:
    - Detect Flower Set (-1) or Plushie Set (-2) in receipt items
    - Use receipt item's `market_price_at_time` as total set MP
    - Calculate each item's proportion of total set MP
    - Expand to individual items with distributed values

2. Update `compareReceipt` to use expanded items:
    - First check if receipt has set items (-1 or -2)
    - If yes, expand them to individual items with distributed values
    - **Total value must match**: After expansion, sum of receipt item `totalValue` must equal trade's total money value
    - **All items must match**: All trade items must be present in expanded receipt items

Example flow:

```typescript
// Receipt has Flower Set (market_price_at_time: 338090)
// Individual flower MPs (from FLOWER_SET_ITEMS):
//   Dahlia: 2445, Orchid: 6925, ..., Banana Orchid: 9696
// Total: 338090 (matches market_price_at_time!)
// Calculate each flower's % of total set MP
// Expand to 11 individual receipt items
// Now compare against trade items which also have individual flowers
// Check: sum(receiptItem.totalValue) === trade.getTotalValue()
// Check: every trade item has matching receipt item
```

### Step 4: Handle mixed receipts (individual items + sets)

Receipts may have both individual items AND sets:

- Process set items first (expand to individuals)
- Keep individual items as-is
- Combine both for comparison

### Step 5: Update Weav3rReceiptItem to include market_price_at_time

The `Weav3rReceiptItem` class needs to track `market_price_at_time` field (only for set items):

- Add optional `marketPriceAtTime?: number` field to Weav3rReceiptItem
- This is used during expansion to calculate item proportions
- Update `Weav3rReceipt.fromApiResponse` to parse this field from the API

```typescript
// Weav3rReceiptItem class changes

    // ...
}
```
