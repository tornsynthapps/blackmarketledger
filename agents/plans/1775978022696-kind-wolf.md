# Plan: Refactor NewRateLimiter to be more OOP

## Current Issues

- Uses unusual pattern: arrow functions assigned as instance properties in constructor
- Typo: `aquire` should be `acquire`
- Duplicated logic across methods (timestamp filtering)
- No proper encapsulation - timestamps array accessible via closure
- No type definitions for the class
- Missing parameter documentation

## Proposed Changes

### 1. Convert to Proper Class Syntax

- Use TypeScript class with proper `constructor`
- Use `private` field for `timestamps` array
- Use standard method declarations instead of arrow functions in constructor

### 2. Add Private Helper Methods

- Extract `getValidTimestamps()` - calculates valid timestamps within window
- Extract `cleanupExpiredTimestamps()` - removes expired timestamps

### 3. Fix Naming

- Rename `aquire` → `acquire` (fix typo)

### 4. Add Type Annotations

- Add return types to all methods
- Add readonly properties for config values

### 5. Optional Enhancements

- Add getter for `requestsPerMinute` config
- Add `reset()` method to clear timestamps
- Add `getAvailableSlots()` method for flexibility
