# App

Application routes for the Black Market Ledger frontend.

## Key Files

- `page.tsx`: Main V2 dashboard showing inventory, realized profit, and charting from the new domain log engine.
- `logs/page.tsx`: New-domain activity log viewer with filtering and cost-basis recalculation controls.
- `treasurechest/`: Developer and admin tools for inspecting and operating on local ledger data.
- `old/`: Legacy journal and migration-era UI still used for older data flows.
