# Plan: Update Accounts Page to Use New Ledger API

## Overview

Update the accounts page to use the new Cloudflare Workers-based Ledger API for authentication, add token reset functionality, implement auth protection on all ledger pages, and enhance the UI with security warnings.

## Components to Update/Create

### 1. New API Client Library

Create `lib/ledger-api.ts` to interface with the new Ledger API:

- `login(userId, secretToken)` - POST /auth/login
- `signupInitiate(userId, mode)` - POST /auth/signup (mode: initiate-message or initiate-money)
- `signupVerify(verificationToken)` - POST /auth/signup (mode: verify)
- `resetTokenInitiate(userId)` - POST /auth/reset-token (mode: initiate)
- `resetTokenVerify(verificationToken)` - POST /auth/reset-token (mode: verify)

### 2. Update Auth Storage

Update `lib/old/token-auth.ts` to:

- Add `getLedgerApiUrl()` helper for the new API endpoint
- The storage format remains the same (localStorage)

### 3. Update Accounts Page (`app/account/page.tsx`)

- Replace imports to use new `lib/ledger-api.ts` instead of `lib/old/token-api.ts`
- Add "Forgot Token" tab/mode for reset token flow:
    - Input for User ID
    - Initiate reset - shows verification message to send
    - Verify - enter verification token to get new token
- Add security warnings UI:
    - Warning banner about storing token securely
    - Never share your token message
    - Token is like a password message

### 4. Auth Protection Middleware

Create `middleware.ts` in `app/` directory to protect all routes:

- Public routes (no auth required):
    - `/public/*`
    - `/docs/*`
    - `/changelog`
    - `/terms`
    - `/privacy`
    - `/links`
- All other routes require authentication via `lib/old/token-auth.ts`
- Redirect unauthenticated users to `/account`

### 5. Environment Variables

Add to `.env.local`:

```
NEXT_PUBLIC_LEDGER_API_URL=https://ledger.tornsynthapps.workers.dev
```

NEXT_PUBLIC_LEDGER_API_URL=<your-ledger-api-endpoint>
