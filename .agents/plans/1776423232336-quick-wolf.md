# Plan: Create Pricelist Schema

## Goal

Create a SQL schema file for a `pricelist` table in `api/db/schemas/`.

## Schema Design

| Column      | Type    | Constraints | Description                 |
| ----------- | ------- | ----------- | --------------------------- |
| user_id     | INTEGER | PRIMARY KEY | User identifier             |
| forum_link  | TEXT    | NOT NULL    | Link to forum post          |
| data_source | TEXT    | NOT NULL    | 'TornW3B' or 'TornExchange' |

## Implementation

1. Create `api/db/schemas/pricelist.sql` with the table definition:
    - `user_id INTEGER PRIMARY KEY`
    - `forum_link TEXT NOT NULL` (SQLite doesn't have a native "link" type, use TEXT)
    - `data_source TEXT NOT NULL` (check constraint for allowed values)

2. Update `api/db/schemas/README.md` to document the new table.

## Notes

- SQLite/D1 doesn't have a separate LINK type - TEXT is used with appropriate validation
- For the data_source enum, use a CHECK constraint to enforce valid values

## Deployment (after implementation)

```bash
wrangler d1 execute ledger --file=db/schemas/pricelist.sql
```
