## 3. Single Supabase Edge Function (Unified)

All endpoints merged into one function with different `action` in body:

### POST / (unified handler)

**Request body structure:**

```typescript
{
    action: "signin" | "initiate_deposit" | "initiate_message" | "verify_signup",
    userId?: string,
    secretToken?: string,
    verificationToken?: string
}
```

**Action handlers:**

#### action: "signin"

- Input: `{ userId, secretToken }`
- Check user_tokens table for matching secret token
- If match: return authenticated=true, subscription details
- If no match: increment failed_attempts
- If failed_attempts >= 5: set is_blocked=true, return error
- Return subscription status (valid_until, etc.)

#### action: "initiate_deposit"

- Input: `{ userId }`
- Generate random X amount ($50-$500 range)
- Generate unique verification token ABC
- Store in token_verification_temp with expiry (e.g., 30 mins)
- Return: `{ amount: X, verificationToken: ABC }`

#### action: "initiate_message"

- Input: `{ userId }`
- Generate random Y message
- Generate unique verification token ABC
- Store in token_verification_temp with expiry
- Return: `{ message: Y, verificationToken: ABC }`

#### action: "verify_signup" (NEEDS UPDATE)

- Input: `{ verificationToken: ABC }`
- Fetch temp record by verification_token
- Call Torn API: `GET https://api.torn.com/v2/user/log?target=<USER_ID>&limit=100`
- **OLD RESPONSE FORMAT (current code):** Uses `/logs?type=account` with `logs: [{id, timestamp, amount, message}]`
- **NEW RESPONSE FORMAT (required):**

```json
{
    "logs": [
        {
            "id": "giZ6CSX5JGeElliTRjjV",
            "timestamp": 1775453315,
            "details": { "id": 4810, "title": "Money receive", "category": "Money sending" },
            "data": { "sender": 2579785, "anonymous": 0, "money": 8000000, "message": "" }
        }
    ]
}
```

- **Update needed:**
    - Change endpoint from `/v2/user/{id}/logs?type=account` to `/v2/user/log?target={userId}&limit=100`
    - **Add timestamp filter:** Use `from={Math.floor((Date.now() - 5 * 60 * 1000) / 1000)}` parameter (5 minutes ago in Unix timestamp)
    - Parse response: `log.data.money` for deposit amount, `log.data.message` for message
    - For deposit verification: Check `log.data.money === amount_required` AND `log.data.sender === torn_user_id` (money sent by user themselves)
    - For message verification: Check `log.data.message === message_required` AND `log.data.sender === torn_user_id`
    - Filter by timestamp within last 30 minutes using `log.timestamp`

## Notes

- Secret tokens are generated from 3 random Torn words (e.g., "ghost-candy-pyramid")
- Verification tokens (ABC) are unique UUIDs
- Failed attempts tracked per user, resets on successful login
- Account blocked after 5 consecutive failed attempts
- Deposit amounts: random between $50-$500
- Verification expiry: 30 minutes

## Database SQL Migration

Run these SQL statements in your Supabase SQL editor to create the required tables:

```sql
-- Table: user_tokens
-- Stores authenticated user tokens with failed attempt tracking

CREATE TABLE IF NOT EXISTS user_tokens (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    torn_user_id BIGINT UNIQUE NOT NULL,
    username VARCHAR(255),
    secret_token_hash VARCHAR(64) NOT NULL,
    failed_attempts INTEGER DEFAULT 0,
    is_blocked BOOLEAN DEFAULT FALSE,
    valid_until TIMESTAMP WITH TIME ZONE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE INDEX idx_user_tokens_torn_user_id ON user_tokens(torn_user_id);
CREATE INDEX idx_user_tokens_secret_token_hash ON user_tokens(secret_token_hash);

-- Table: token_verification_temp
-- Temporary storage for signup verification tokens

CREATE TABLE IF NOT EXISTS token_verification_temp (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    torn_user_id BIGINT NOT NULL,
    verification_token VARCHAR(64) UNIQUE NOT NULL,
    verification_type VARCHAR(20) NOT NULL CHECK (verification_type IN ('deposit', 'message')),
    amount_required INTEGER,
    message_required VARCHAR(255),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    expires_at TIMESTAMP WITH TIME ZONE NOT NULL
);

CREATE INDEX idx_token_verification_temp_token ON token_verification_temp(verification_token);
CREATE INDEX idx_token_verification_temp_expires ON token_verification_temp(expires_at);
```
