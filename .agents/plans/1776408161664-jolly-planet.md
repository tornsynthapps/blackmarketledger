# Plan: Add Item Grouping to Dashboard

## Goal

Add grouping functionality to the main dashboard (home page) similar to the pricelist page, allowing users to toggle between grouped-by-type and ungrouped views.

## Current State

- **Pricelist** (`/app/pricelist/PricelistClientPage.tsx`): Already has grouping by item type with toggle button
- **Dashboard** (`/app/page.tsx`): Displays inventory in a table, no grouping

## Implementation Steps

### 1. Add State and Storage

- Add `isGrouped` state variable (default: true)
- Add `itemTypeMap` state to store item type data from `/items.json`
- Add localStorage key `bml-dashboard-grouped-pref` to persist preference
- Load item types on mount (similar to pricelist: `fetch("/items.json")`)

### 2. Add Toggle Button

- Add "Grouped" toggle button in the inventory header section, next to search input
- Style matches pricelist: icon changes appearance based on grouped/ungrouped state

### 3. Create Grouping Logic

- Add `groupedItems` useMemo that:
    - Returns `null` if `!isGrouped`
    - Groups inventory items by type (from `itemTypeMap`)
    - Falls back to "Other" for unknown types
    - Returns sorted array of [type, items] pairs

### 4. Update Rendering

- Conditionally render:
    - **Grouped view**: Show category sections with headers (type name + item count), each containing grid of item cards
    - **Ungrouped view**: Keep existing table format
- Use `PublicPricelistCard` or similar component for grouped display (same as pricelist)

### 5. Dependencies

- Import `StarIcon` from `@hugeicons/core-free-icons` (already used in pricelist)
- Reuse `/items.json` for item type mapping (already exists)

## Files to Modify

- `/app/page.tsx` - Main dashboard component

## UI Pattern (from pricelist reference)

```tsx
{isGrouped && groupedItems ? (
    groupedItems.map(([type, items]) => (
        <div key={type}>
            <div className="flex items-center gap-4">
                <h3>{type}</h3>
                <span>{items.length} Items</span>
            </div>
            <div className="grid grid-cols-1 md:grid-cols-2 xl:grid-cols-3">
                {/* Item cards */}
            </div>
        </div>
    ))
) : (
    /* Table view */
)}
```
