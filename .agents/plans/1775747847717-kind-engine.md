# Plan: Set Pricelist from Museum

## Overview

Add "Set Pricelist" mode to Museum page for flower and plushie sets. Users can view their current pricelist settings and update them directly from Museum. Include an "Auto" button that calculates optimal pricing percentages based on current stock levels.

## API Endpoints (Weav3r)

### GET Current Pricelist

```
GET https://weav3r.dev/api/pricelist/{userID}?apiKey={apiKey}
```

Returns array of `{ itemId, name, buyPrice }`

### GET Market Prices

```
GET https://weav3r.dev/api/marketplace
```

Returns items with `market_price`

### Update Pricelist

```
PUT https://weav3r.dev/api/pricelist/{userID}?apiKey={apiKey}
```

Body:

```json
{
    "items": [
        {
            "itemID": 123,
            "pricingType": "market_percentage",
            "pricingValue": 95,
            "inflationProtectionEnabled": false,
            "roundToPlace": 0
        }
    ]
}
```

## Implementation

### 1. Add New State Variables (app/museum/page.tsx)

- `flowerPricelistMode` / `plushiePricelistMode`: boolean to show pricelist view
- `flowerPricelistData` / `plushiePricelistData`: Record<itemName, { currentPrice, marketPrice, percentage }>
- `isFetchingPricelist`, `isUpdatingPricelist`: loading states

### 2. Fetch Market Prices & Pricelist

- Add useEffect to fetch from Weav3r when pricelist mode is opened
- Fetch both market prices (`/marketplace`) and user's pricelist (`/pricelist/{userID}`)
- Calculate percentage: `(buyPrice / marketPrice) * 100`

### 3. Create Pricelist UI Component

For each set (flower/plushie), show:

- Grid of items with: Item Name | Stock | Market Price | Current Pricelist % | New % input
- "Auto" button that calculates % based on configurable stock thresholds (default thresholds shown below)
- Threshold settings panel (collapsible):
    - Threshold 1 (default: 500) → Offer % (default: 101)
    - Threshold 2 (default: 1000) → Offer % (default: 100)
    - Threshold 3 (default: 2000) → Offer % (default: 98)
    - Else → Offer % (default: 95)
- "Save Pricelist" button to PUT updates to Weav3r API

### 4. Add Threshold Configuration UI

- Add localStorage keys: `museum-pricelist-thresholds` to persist user-defined thresholds
- Allow users to customize both the stock thresholds and corresponding offer percentages

### 4. Toggle Button

Add "Set Pricelist" button next to "Buy Plan" in each set section

### 5. Error Handling

- Show warning if Weav3r API key not configured
- Handle API errors gracefully

## Files to Modify

- `app/museum/page.tsx` - Add pricelist mode UI and functionality

## Stock Threshold Logic (Auto Button - User Configurable)

Default thresholds (can be customized by user):
| Stock Range | Default Offer % |
|------------|----------|
| <= Threshold1 (500) | 101% |
| <= Threshold2 (1000) | 100% |
| <= Threshold3 (2000) | 98% |
| > Threshold3 | 95% |

Users can edit both the stock thresholds and the offer percentages via a settings panel.

## User Flow

1. User clicks "Set Pricelist" button on Flower/Plushie section
2. System fetches market prices and user's current pricelist
3. Grid displays each item with stock, market price, current %, and editable % field
4. User can manually edit % or click "Auto" to calculate based on stock
5. User can customize thresholds via settings panel
6. User clicks "Save" to update pricelist via Weav3r API
