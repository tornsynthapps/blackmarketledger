# Plan: Populate Item.ts with all items from items.json

## Goal
Replace the sparsely populated `lib/objects/Item.ts` with a complete `ItemList` class containing all ~1,473 items (1-1509 with gaps) from `data/torn/items.json`, plus the existing virtual money items (CASH, POINTS).

## Approach

Write a Node.js script (`scripts/generate-item-constants.ts`) that:

1. Reads `data/torn/items.json`
2. Extracts all `(id, name)` pairs
3. Converts each item name to a valid UPPER_SNAKE_CASE TypeScript constant identifier
4. Generates the full `lib/objects/Item.ts` file

## Name Conversion Rules

- Remove/replace special characters: `'`, `’`, `:`, `&`, `/`, `.`, `®`, `-` (hyphens become underscores), `(` / `)`, etc.
- Convert to uppercase
- Replace spaces with underscores
- Collapse multiple consecutive underscores
- Strip leading/trailing underscores

Examples:
- "S&W Revolver" → `S_W_REVOLVER`
- "Mr Torn Crown '07" → `MR_TORN_CROWN_07`
- "Blood Bag : A+" → `BLOOD_BAG_A_PLUS`
- "AK-47" → `AK_47`
- "M'aol Visage" → `M_AOL_VISAGE`
- "Rhino's Horn" → `RHINOS_HORN`
- "eCPU" → `ECPU`

## Implementation Steps

1. Write a Node.js script (`scripts/generate-item-constants.ts`) that:
   - Reads and parses `data/torn/items.json`
   - Converts names to constants
   - Generates the complete file content
   - Handles edge cases (missing IDs like 589-592, 891, 999-1000, etc.)

2. Run the script with `npx ts-node scripts/generate-item-constants.ts` (or compile and run)

3. Verify the output:
   - Confirm the file compiles with `npx tsc --noEmit lib/objects/Item.ts`
   - Check that existing imports still work (no breaking changes to `ItemList.POINTS`, `ItemList.TEDDY_BEAR_PLUSHIE`, etc.)
   - The existing constants (DAHLIA=260, TEDDY_BEAR_PLUSHIE=187, KITTEN_PLUSHIE=215, MONKEY_PLUSHIE=269) must match the JSON values

## Key Considerations

- The file will be ~1,500 lines — this is expected and acceptable for a constants file
- **Name collisions after normalization**: There are at least 2 items named "Unknown" (different IDs). The script must detect collisions and disambiguate (e.g., `UNKNOWN_765` and `UNKNOWN_1200` using their IDs, or `UNKNOWN_1` / `UNKNOWN_2`).
- The constants should be sorted by item ID for maintainability
- Only IDs that exist in the JSON should be included (gaps are expected, e.g., 589-592, 891, 999-1000, 1160-1163, 1218, 1229, 1432-1447)
- The virtual money items (100001, 100002) are NOT in the JSON and must be preserved manually
- Organize with comment section headers for readability (e.g., `// Melee Weapons`, `// Firearms`, `// Medical`, `// Drugs`, etc.) or keep it simple with `// Items 1-100`, `// Items 101-200`
