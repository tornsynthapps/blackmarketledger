### Receipt Methods (Single-Pass)
- `getReceipt(receiptId)` - GET `/api/receipt/{receipt_id}` - fetch single receipt with full line items
- `getReceipts(from, to?, options?)` - GET `/api/receipts` - fetch all receipts with pagination
  - Returns summary list directly from endpoint (no second call for line items)
  - Supports date filtering via from/to params
  - Handles pagination automatically (100 per page, loops through all pages)

### Pricelist Methods (All Batch-Based - matching TE API)
- `getPricelist(identifier)` - GET `/api/prices/{identifier}` - fetch a trader's full pricelist by Torn ID or username
- `delistItems(itemIds)` - DELETE multiple listings via POST `/api/modify_listing` with action=delete
  - itemIds: array of item IDs to remove
- `updateItemPricesByPercentage(updates)` - update multiple prices using discount/premium percentage
  - updates: array of `{ itemId, percentage }`
  - percentage: Input represents % of TE market value to charge
  - 95 → 5% discount, 100 → no change, 105 → 5% premium
  - Internally converts to discount: `discount = 100 - percentage` (can be negative)
- `updateItemPricesByFixed(updates)` - update multiple prices using fixed Torn currency amounts
  - updates: array of `{ itemId, price }`
- Uses single POST `/api/modify_listing` batch call for all update operations

### Additional Methods
- `getMyPricelist()` - convenience: get YOUR pricelist using stored TE API key as identifier
- `getAllPrices()` - GET `/api/all_prices` - get TE and Torn market prices for all items

## TE API Endpoints Needed

| Method | Endpoint | Description |
|--------|----------|-------------|
| getReceipt | GET /api/receipt/{receipt_id} | Fetch single receipt (no auth) |
| getReceipts | GET /api/receipts | Fetch user's receipts (auth required, paginated, supports from/to date filters) |

### Pagination Strategy (Single-Pass)
- Fetch receipt summaries directly from `/api/receipts` endpoint
- Default: 100 receipts per page
- Use `page` param to iterate through pages until `meta.total_pages` reached
- No second call for line items (only getReceipt fetches full details)
