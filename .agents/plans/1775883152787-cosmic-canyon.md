# Plan: Compact Central Directory (/links) Page

## Goal

Make the /links page compact so all items fit within page height along with the footer.

## Current Issues

- Large vertical padding (`py-12` = 48px)
- Large gaps between sections (`gap-12` = 48px)
- Large title typography (`text-4xl` to `text-5xl`)
- Large card padding (`p-6` = 24px)
- Hover translate effects take additional space

## Changes to Make (in `app/links/page.tsx`)

### 1. Container (line 112)

- Change `py-12` to `py-4`
- Change `gap-12` to `gap-4`

### 2. Header Title (line 114)

- Change `text-4xl` to `text-2xl`
- Change `sm:text-5xl` to `sm:text-3xl`
- Reduce `pl-6` to `pl-4`

### 3. Section Headers (lines 123-127, 164-168)

- Change `text-xl` to `text-sm`
- Change `mb-8` to `mb-3`

### 4. Grid Container (lines 130, 171)

- Keep `gap-1` for tight grid

### 5. Link Cards (lines 136, 177)

- Reduce `p-6` to `p-3`
- Reduce `gap-4` to `gap-2`
- Remove `hover:translate-x-1 hover:-translate-y-1` hover effects

### 6. Card Interior (lines 138-157, 179-198)

- Reduce icon container: `p-3` → `p-2`
- Reduce icon size: `size={24}` → `size={16}`
- Reduce title `text-lg` → `text-sm`
- Reduce description `text-xs` → `text-[10px]`
- Reduce `mt-1` → `mt-0.5`

## Expected Result

- Page will be significantly more compact
- All content fits within viewport height with footer visible
- Maintains readability and navigation functionality
