# userscript

Directory path: `userscript`

## Purpose

Torn browser userscript for seamless integration and automatic log tracking.

## Files & Contents

- **`bml-listener.js`**: Logs events to a "blackbox" stored in localStorage for debugging purposes.
- **`bml.user.js`**: Module file providing specific functionality for this directory.
- **`build.mjs`**: Build script for the BML Userscript.
- **`core.js`**: Module file providing specific functionality for this directory.
- **`legacy.user.js`**: Module file providing specific functionality for this directory.
- **`styles.js`**: Module file providing specific functionality for this directory.
- **`torn-bazaar.js`**: Processes a single bazaar item row, injecting cost basis information if available.
